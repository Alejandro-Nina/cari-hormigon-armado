# CARI · Hormigón armado

Aplicación web para diseño preliminar estructural y cálculo de hormigón armado.

## Descripción
Proyecto estático para cálculo y presentación de conceptos de diseño estructural, con enfoque en hormigón armado y visualización técnica.

## Uso
- Abrir `index.html` en el navegador, o
- Servir la carpeta con un servidor local.

## Publicación
Este repositorio está preparado para GitHub Pages.
